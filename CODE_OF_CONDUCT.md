# Código de conduta

Este projeto adota o **Contributor Covenant, versão 2.1**, por referência. O texto oficial (em inglês) está em:

<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>

*This project adopts the Contributor Covenant, version 2.1, by reference; the official text is at the link above.*

Em resumo: seja respeitoso, aceite crítica construtiva, foque no que é melhor para a comunidade e não pratique assédio, ataques pessoais nem divulgação de dados privados de outras pessoas. O código de conduta vale em issues, pull requests e demais espaços do projeto.

## Denúncias

Para relatar um comportamento inaceitável, entre em contato com os mantenedores pelo GitHub: abra um relato privado pelo recurso de aviso de segurança do repositório se o caso for sensível (veja [`SECURITY.md`](SECURITY.md)) ou mencione [@decolla](https://github.com/decolla) em uma issue, sem expor dados de terceiros. Os mantenedores tratam as denúncias com discrição e aplicam as consequências descritas no texto oficial.
